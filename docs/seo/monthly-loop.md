# Monthly SEO Routine

Once a month, give Claude a Search Console export and ask it to run this routine. No login details need to be stored.

## 1. Check

In Search Console, open **Performance**, set the last 28 days, and use **Export > CSV**. Put the export in the conversation.

AI answer checks are on hold. Skip them until you decide to restart them.

## 2. Compare

Compare with the entries in [log.md](log.md). Look for trends across months, not one-off changes. Separate searches for "Voxa" from all other searches.

## 3. Decide

Use these rules:

- **Impressions with few clicks:** improve that page's title or direct answer.
- **Relevant searches with no strong page:** add or improve a page or article.

These apply only once AI checks restart:

- **Voxa is described wrongly:** fix the site or the profiles.
- **Voxa is missing and answers mostly cite other sites:** pursue listings or reviews, and consider active PR.

## 4. Prepare

Write a short brief with one or two content items, plus any review and listing tasks. Reviews and listings are about 20% of the effort for now.

## 5. Approve

You review, edit and approve everything. Before anything is published, check:

- [ ] Every claim traces to you or an existing source, with no invented clients, results, reviews, prices or statistics
- [ ] Nothing implies scripting, funnel strategy or ad-buying services
- [ ] Clients named or quoted have given permission
- [ ] Copy shows that scope is flexible, not a locked menu
- [ ] It's a genuinely useful page, not a near-duplicate made for a keyword
- [ ] No On-Site content, until that section is ready
- [ ] Booking and tracking still work

## 6. Log

Add what you found and what shipped to [log.md](log.md).
